Model 2: Random Forest Documentation

- Notebook: [scripts/model2-random-forest.ipynb](scripts/model2-random-forest.ipynb)

Purpose:
Builds a random forest classifier to predict customer churn and compares performance to Model 1.

Steps performed:
1. Import libraries ('scikit-learn', 'pandas').
2. Load feature-engineered dataset.
3. Train random forest model with tuned hyperparameters.
4. Evaluate performance using accuracy, precision, recall and confusion matrix.
5. Compare results with logistic regression baseline.
